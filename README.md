# Simulador de Variables de Proceso para Lazos de Control Industrial

Proyecto desarrollado como trabajo final de Ingeniería Electrónica.

El sistema permite simular variables de proceso industriales mediante
señales analógicas de 4–20 mA para el ensayo y ajuste de lazos de control.

## Características principales

- Generación de señales 4–20 mA.
- Lectura de señales 4–20 mA.
- Simulación de procesos de primer orden.
- Configuración de ganancia, constante de tiempo, retardo, offset y ruido.
- Interfaz local mediante display OLED.
- Interfaz web mediante Wi-Fi.
- Presets para diferentes variables de proceso.
- Calibración de entrada y salida.
- Plataforma basada en ESP32-S3.

## Estructura del repositorio

- `Firmware/`: código fuente del ESP32-S3.
- `Hardware/`: esquemáticos y diseño de PCB.
- `Gabinete_3D/`: archivos del gabinete.
- `Documentacion/`: documentación técnica del proyecto.
